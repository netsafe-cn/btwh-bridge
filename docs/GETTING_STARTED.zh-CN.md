# 燃热桥 · 小白安装指南

这份文档假设你**没有写过代码、也没用过 Arduino**。按顺序做完，你会得到一个小盒子：
插在热水器旁边，家里 WiFi 就能读到热水器的水温、火焰、故障码，也能远程调温度。

全程大约 **40 分钟**，其中真正动手的只有三次：买板子、刷固件、手机上填一张表。

---

## 0. 先说清楚三件事

1. **家里的 WiFi 必须是 2.4GHz。** ESP32 这块芯片只认 2.4G，5G 网络它看不见。
   大多数路由器是 2.4G + 5G 双频，手机连的可能是 5G，但 2.4G 那个名字一般也还在。
2. **热水器面板上要能显示 6 位数字。** 这是配对码，第 5 节会教你按出来。它是**面板上显示的码**，
   不是机器铭牌上的 S/N 序列号。
3. **这东西不联网也能活着，但不联网就没有意义。** 桥的全部工作是把热水器的蓝牙数据
   转成 WiFi 上的消息，所以 WiFi 和配对缺一不可。

---

## 1. 准备清单

| 需要什么 | 说明 |
|---|---|
| ESP32-S3 开发板 ×1 | 见第 2 节怎么买。**建议多买一块**，刷坏了不耽误事，也就几十块 |
| USB-C 数据线 ×1 | **必须是能传数据的**。很多充电线只有两根电源线，插上电脑毫无反应 |
| 5V 充电头 ×1 | 手机充电头即可（5V 1A 足够），插在热水器附近的插座上 |
| 手机 ×1 | 用来配网，安卓 / iPhone 都行 |
| 电脑 ×1 | Windows 10/11 最省事，用来刷固件。只有这一步需要电脑 |
| 家里 WiFi 密码 | 就是平时连 WiFi 那个 |
| 热水器 | 博世 Therm 系列（本工程实测 4800i）。面板要能操作菜单 |

## 2. 第一关：买对板子

**要买的是"开发板"，不是芯片。** 芯片是焊在板子上的小黑方块，你没法直接接线。

### 认这三个字：ESP32-S3

商品标题里必须有 **ESP32-S3**，少一个字母都不行。

| 你可能会看到的 | 能不能用 | 为什么 |
|---|---|---|
| **ESP32-S3**（如 ESP32-S3-DEV-KIT、ESP32-S3-DevKitC） | ✅ 可以 | 就是它 |
| ESP32-C3 / ESP32-S2 | ❌ 不行 | 芯片不一样，固件刷不进去 |
| ESP32-WROOM-32 / ESP32-DevKitC（没有 S3） | ❌ 不行 | 这是上一代 ESP32，内存和分区都不同 |
| ESP8266 / NodeMCU | ❌ 不行 | 更老，没有蓝牙 |

### 认两个参数

- **Flash 8MB 起步**（商品名里常写 N8R8 或 N16R8，8 就是 8MB Flash，16 就是 16MB）
- **板载 USB 转串口芯片**（一般标 CH343 / CH340 / CP2102）

本工程实测用的是一块 **微雪（Waveshare）ESP32-S3-DEV-KIT**，丝印写 N8R8，实测 16MB Flash。
淘宝、微雪官网、立创商城搜 **"ESP32-S3-DEV-KIT N16R8"** 都能找到，百元以内。

### 三个避坑提示

1. **板子有两个 USB-C 口时，插标着 UART（或 COM、CH343）的那个**，那是烧录口；
   另一个是芯片原生 USB，刷固件用它容易踩坑。
2. **别买"仅焊接排针"的裸板**，除非你打算自己焊。带排针焊好的贵几块钱，省半小时。
3. **多买一块。** 这不是危言耸听：刷错固件、买错型号、把 5V 接到 3.3V，都会让第一块板子报废，
   而第二块当天就能到。

> 不想自己刷？**直接找一台已经刷好固件的板子**（朋友、卖家、或任何有电脑基础的人用附录 A 刷一块），
> 你从第 4 节开始做就行。

## 3. 第二关：把固件刷进板子

"固件"就是板子的操作系统。空的 ESP32 插上电什么都不做，刷进去之后它才知道自己是热水器桥。

### 3.1 先拿到固件文件

你需要一个文件，叫 **`btwh-bridge-full.bin`**（约 1.2MB）。来源二选一：

- 别人给你（微信传文件即可，这是唯一需要的文件）
- 自己生成（需要一点点电脑操作，见 [附录 A](#附录-a自己构建固件)）

这个文件是"整包镜像"，一个文件包含引导程序、分区表和应用程序，所以只需要烧一个地址。

### 3.2 插上板子，看电脑认不认

1. 装驱动（只有一次）：搜 **WCH CH343 驱动**，从 `wch.cn` 下载安装。Windows 11 有时免驱，
   先插上看看再说。
2. 用 USB-C 线把板子插到电脑。
3. 右键"此电脑" → 管理 → **设备管理器** → 展开 **端口 (COM 和 LPT)**。

**你会看到**类似这样一行：

```
USB-Enhanced-SERIAL CH343 (COM8)
```

后面的 `COM8` 就是端口号，**每台电脑不一样**（COM3、COM5 都可能），记下来，下一步要用。

> **看不到这一行？** 99% 是线的问题。换一根确定能传数据的线（比如手机原装数据线），
> 或者换一个 USB 口。板子上的电源灯亮不代表线能传数据。

### 3.3 刷进去（两种方式，选一种）

#### 方式 A：图形界面，不需要命令行（推荐给完全不想敲命令的人）

1. 搜索并下载乐鑫官方 **Flash Download Tool**（Espressif 官网 → 支持 → 下载 → Flash 下载工具）。
   解压后双击 `flash_download_tool.exe`。
2. 芯片选 **ESP32-S3**，工作模式选 **Develop**，确定。
3. 表格第一行：
   - 左边 `...` 按钮选你那个 `btwh-bridge-full.bin`
   - 右边地址框填 **`0x0`**（零、x、零）
   - 前面打勾
4. 右下角 **COM** 选你在设备管理器看到的那个号（比如 COM8），**BAUD** 选 `460800`。
5. 点 **START**，等进度条走完，出现绿色的 **FINISH**。
6. 拔掉 USB，再插上（让它重新启动）。

#### 方式 B：一条命令（比看上去简单）

1. 装 Python（`python.org` 下载，安装时勾选 "Add Python to PATH"）。
2. 打开"命令提示符"（开始菜单搜 `cmd`），输入：

```bat
pip install esptool
```

3. 把 `btwh-bridge-full.bin` 放到桌面，然后依次输入（把 `COM8` 换成你的端口号）：

```bat
cd %USERPROFILE%\Desktop
python -m esptool --chip esp32s3 --port COM8 write_flash 0x0 btwh-bridge-full.bin
```

4. 屏幕上滚一堆字，最后出现这两行就算成功：

```
Wrote 1236944 bytes ...
Hash of data verified.
```

### 3.4 怎么确认刷成功了

板子重新上电后，**手机 WiFi 列表里会多出一个 `BTWH-Bridge-XXXX`**（XXXX 是四个十六进制字符）。
看到它，说明固件活了、而且正在等你配网。

> ⚠️ 这个整包镜像会**清空板子里原来存的所有设置**（WiFi、配对码）。全新板子无所谓；
> 如果你是在一块已经在用的板子上重刷，刷完必须重新配一遍网。

## 4. 第三关：配网填表（手机操作）

配网的意思是：告诉板子家里 WiFi 叫什么、密码是多少。

**这一关不要一口气做完。** 表先填到一半，去热水器面板拿配对码，再回来一次提交——
配对码和 WiFi 密码必须在**同一次**提交里进去，因为一旦保存，板子会立刻关掉自己的热点
（就是你现在手机连着的那个），页面也就打不开了。所以第 4 节和第 5 节是一件事，别中间按保存。

1. 板子插上电（用充电头，别一直挂在电脑上），**等 10 秒**。
2. 手机打开 WiFi 列表，连 **`BTWH-Bridge-XXXX`**。
3. 密码是 **`bridge123`**（全部小写，没有空格）。
4. 连上后手机一般会**自动弹出**一个设置页面。没弹？打开手机浏览器，地址栏输入：

```
http://192.168.4.1/
```

页面是英文的，一共四段。对照着填：

| 页面上的英文 | 中文意思 | 怎么填 |
|---|---|---|
| **1 · Your heater** → `Heaters in range` | 附近的热水器 | 下拉里选你家热水器。名字和热水器面板上显示的一致 |
| **2 · Wi-Fi** → `Network` / `Password` | 网络 / 密码 | 选家里的 **2.4G** 网络，输 WiFi 密码 |
| **3 · Pairing code** → 六位数字框 | 配对码 | **先空着**，第 5 节拿到码再回来填 |
| **4 · MQTT broker** | 消息服务器 | **没有 Home Assistant 就整段留空** |
| **Save and connect** | 保存并连接 | 最后按这个按钮 |

> **下拉里没有热水器？** 说明板子没听到热水器的蓝牙广播。热水器长时间不用会休眠，
> 按一下它的面板（或放几秒钟热水）唤醒，然后刷新页面。
>
> **WiFi 列表里没有你家网络？** 大概率是 5G。ESP32 只能看 2.4G，请找名字里没有
> `5G` / `_5G` 的那个。

**前两段填好之后，先别按 Save** —— 直接去第 5 节拿配对码。

---

## 5. 第四关：配对热水器（拿 6 位码）

这是唯一需要动热水器面板的一步，也是**最容易做错**的一步。

原因：配对码在面板上只停留很短时间（几十秒到几分钟），而配网页面**只能连板子自己的热点
（`BTWH-Bridge-XXXX`）打开**——一旦保存，板子就关掉热点去连你家 WiFi 了，页面也就没了。
所以码必须和 WiFi 密码**在同一张表里一次提交**。

顺序就是：**先把表填到一半 → 去按面板出码 → 回来填码 → 立刻保存。**

### 5.1 确认那张表还在

第 4 节填过的页面别关。如果手机中途断开了热点、页面刷新丢了：

1. 重新连 `BTWH-Bridge-XXXX`（密码 `bridge123`），打开 `http://192.168.4.1/`
2. 第 1 段重新选热水器（列表是空的？先按一下热水器面板唤醒它，再刷新）
3. 第 2 段重新选 2.4G 网络、输密码
4. 第 3 段**仍然空着**，别急着填——先去拿码

### 5.2 去按热水器面板，把码按出来

1. 面板菜单里找到 **清除配对**（Clear pairing / 解除配对）并执行——这一步是"打开配对窗口"，
   **不能跳过**
2. 再选 **连接 / 配对**（Connect / Pair）
3. 屏幕显示 **6 位数字**。这就是配对码

> 不同型号的博世面板措辞略有差异，认"清除配对"和"连接/配对"这两个动作就行。
> 拿不准就拍张照，码只亮一会儿。

### 5.3 回来填码，立刻保存

1. 手机可能因为"这个热点没有网络"自动跳回移动数据——重新连上 `BTWH-Bridge-XXXX`，
   页面如果失效了就重新打开 `http://192.168.4.1/`，把前两段再填一次（**这一步要快**）
2. 第 3 段填刚才那 6 位数字
3. 按 **Save and connect**

按下去之后热点会消失（板子去连家里 WiFi 了），**热点消失就是提交成功**。
如果页面跳回来、上面出现红字，说明码或 WiFi 密码有问题，看提示改。

### 5.4 怎么知道配对成功了

- 接了 Home Assistant：水温、火焰这些数字开始在 4 秒内跳动
- 没接 HA：把板子接回电脑，串口（115200）里敲 `status`，看 `phase` 这一行——
  **`connected, listening`** 就是配对并登录成功；`last attempt failed` 就是没成，
  上一行 `last` 会写原因
- 最硬的证据：**断电重启一次**，什么都不用做，几分钟内数据自己恢复

**配对成功后这个码会被板子记住**。以后断电、重启、路由器重启都会自动重连，不用再按面板。
只有在热水器那边又"清除配对"之后，才需要重新来一次。

## 6. 第五关（可选）：接到 Home Assistant

如果你家有 Home Assistant，第 4 节那张表的第 4 段就别留空了：

| 字段 | 填什么 | 例子 |
|---|---|---|
| `Broker address` | HA 那台机器的 IP（跑 Mosquitto 的那个） | `192.168.9.206` 或 `192.168.9.206:1883` |
| `Username` / `Password` | MQTT 账号密码，没设就留空 | `btwh` / 你的密码 |

保存后，板子会自己向 HA 申报 **1 个设备 + 22 个实体**，不需要你在 HA 里配置任何 YAML：

- **12 个实时数据**：出水温度、进水温度、燃烧室温度、机箱温度、设定温度（可调）、
  水流量、火力、风机转速、是否在燃烧、工作模式、故障码、故障告警
- **8 个诊断信息**：固件版本、板子型号、热水器蓝牙地址、配对状态、运行时长、
  蓝牙信号强度、上次断线原因、上次断线时间
- **1 个热水器总控** + **1 个固件更新**按钮

> HA 里设备名默认叫 `Water heater`，可以自己改成"一楼厨房热水器"之类。

## 7. 怎么确认它真的在工作

三步自检，30 秒：

1. **开热水**：Home Assistant 里的出水温度应该在 4 秒内开始变化。
2. **拔掉板子的电源**：HA 里那些实体应该在**几秒内**变成灰色（不可用），
   **而不是继续显示最后的数字**——这条很重要，它证明你看到的数字不是过期缓存。
   如果只是热水器断了（板子还在通电），变灰会慢一些，大约 90 秒后。
3. **看设备页**：应该能看到固件版本（如 `2.9.0-ota8`）。看不到说明发现消息没送到。

## 8. 出问题了怎么办

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 手机搜不到 `BTWH-Bridge-XXXX` | 板子已经存过 WiFi，不会自动开热点 | 见下面"怎么重新配网" |
| 连上热点但不弹设置页 | 手机没做强制门户检测 | 浏览器手动打开 `http://192.168.4.1/` |
| 保存后一直连不上家里 WiFi | 密码错 / 选成了 5G / 信号太弱 | 重配一次，选 2.4G；把板子挪近路由器试试 |
| 保存后热点没消失 | 表单没提交成功 | 检查页面红字提示，重新提交 |
| 配对总是失败 | 配对窗口已经关了（码过期） | 面板重新"清除配对"，会出一个**新码** |
| 热水器时好时坏、经常断 | 蓝牙距离太远 / 热水器休眠 | 板子挪近热水器；长时间不用时按键唤醒 |
| HA 里实体一直是灰的 | MQTT 账号密码错 / broker 地址错 | 重配第 4 段；确认 HA 上 Mosquitto 在跑 |
| 家里 WiFi 变了名字或密码 | 板子连不上了 | 见下面"怎么重新配网" |

### 怎么重新配网

板子连不上 WiFi 时，它**不会**自己退回热点模式（这是目前的设计：避免一个能改设置的页面
长期暴露在网络上）。所以重新配网需要一根 USB 线和一台电脑：

1. 板子用 USB 线插到电脑
2. 打开任意串口工具（如 PuTTY、串口助手、Arduino 串口监视器），**波特率 115200**
3. 在输入框里打 `portal` 回车
4. 板子会在你家局域网里开一个配置页，串口会打印类似：

```
[PORTAL] LAN mode: http://192.168.9.55/  (same network, nothing to switch)
```

5. 用浏览器打开这个地址，就是第 4 节那张表，改完保存

> 这一步是目前最不友好的地方，如果你觉得麻烦，可以在项目里提一个"WiFi 连续失败 5 分钟后
> 自动开热点"的需求。

## 附录 A：自己构建固件

适合"电脑基础还行"的人。需要：Windows / macOS / Linux，Python 3.10+，`arduino-cli`。

```bash
git clone https://github.com/netsafe-cn/btwh-bridge.git
cd btwh-bridge

# 编译 + 烧录（--flash 会先自动编译，一条命令就够）
# 改过头文件就加 --clean，否则会用旧的编译产物
python firmware/bridge/tools/gateway_cli.py --flash

# 只编译不烧
python firmware/bridge/tools/gateway_cli.py --build
```

想做出那个"一个文件"的整包镜像（给别人刷）时：

```bash
cd <构建输出目录>          # gateway_cli.py 会打印这个路径，通常是 ~/esp/build
esptool --chip esp32s3 merge_bin -o btwh-bridge-full.bin \
  --flash_mode dio --flash_freq 80m --flash_size 16MB \
  0x0     arduino_sketch.ino.bootloader.bin \
  0x8000  arduino_sketch.ino.partitions.bin \
  0xe000  <arduino-esp32>/tools/partitions/boot_app0.bin \
  0x10000 arduino_sketch.ino.bin
```

烧这个整包时地址是 **`0x0`**，一个文件搞定，其余什么都不用填。

## 附录 B：串口常用命令

连上 115200 的串口后可以直接打字（回车执行）：

| 命令 | 作用 |
|---|---|
| `status` | 一屏看全：配对阶段、WiFi、broker、数据年龄、失败原因 |
| `115226` | 直接输 6 位码 = 立刻配对并登录 |
| `pair` | 清掉本地绑定，强制重新做一次蓝牙配对 |
| `go` | 用已存的码重连（不用重新配对） |
| `portal` | 在局域网开配置页（就是上面说的重新配网） |
| `wifi <名字> <密码>` | 直接写 WiFi 配置并立刻连接 |
| `broker <地址>` | 改 MQTT 服务器；`broker -` 清空 |

失败对照表（`A2/08` 那些码是什么意思）在
[`firmware/bridge/README.md`](../firmware/bridge/README.md) 里。

## 一句话总结

**买一块 ESP32-S3 → 刷一个 bin → 手机连它的热点 → 填 WiFi 和热水器面板上的 6 位码 → 完事。**
之后的每一天，它自己断电重连、自己重配对、自己向 Home Assistant 报到。
